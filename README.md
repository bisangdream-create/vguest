# 방 명 록 🌸

체험을 해보시고 좋았던 점이나 개선점을 남겨 주세요.^^

## 🌟 주요 기능
- **따뜻한 연한 노란베이지 톤 디자인**: 마스킹 테이프 및 포스트잇 질감의 아기자기한 디자인
- **3가지 포스트잇 선택**: 햇살 노랑, 벚꽃 핑크, 민트 하늘 선택 가능
- **개인 핀번호(4자리)**: 작성한 메모를 수정 및 삭제
- **실시간 반응형 레이아웃**: 가로 4~5열로 20~30개 이상의 메모를 한눈에 확인
- **PDF 다운로드**: 작성된 방명록을 PDF 파일로 저장
- **관리자 기능**: 전체 초기화 및 방명록 제목 변경 (기본 관리자 비밀번호: `1234`)

## 🚀 Vercel 배포 방법
1. 이 프로젝트를 GitHub 리포지토리에 업로드(Push)합니다.
2. Vercel(https://vercel.com)에 로그인 후 **New Project**를 생성합니다.
3. GitHub 리포지토리를 선택하고 **Deploy** 버튼을 누르면 배포가 완료됩니다!
